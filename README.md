# Сайт-визитка «Морской Снабженец» (Судовое снабжение / Shipchandler)

Современный, семантичный, адаптивный статический многостраничный сайт для шипчандлинговой компании (судовое снабжение в морских портах РФ).

Проект сверстан на **чистом HTML5 / CSS3 / Vanilla JS** без сторонних тяжелых библиотек и зависимостей, оптимизирован под быструю интеграцию в тему **WordPress**.

## ⚓ Секции на Главной странице (`index.html`)

1. **Topbar & Header (Sticky)**: Логотип, выпадающие подменю («Услуги» — 7 пунктов, «Морские суда» — 6 типов, «Порты», «Контакты»), переключатель RU/EN, телефон 24/7 и кнопка «Оставить заявку».
2. **Hero-секция**: УТП заголовок, список обслуживаемых портов, бейджи надежности, ключевые метрики и CTA-кнопки со скроллом к форме.
3. **Товары и продукты (10 карточек)**: Сетка 10 карточек с номерами 01–10, тематическими фото, описанием и ссылками на подстраницы.
4. **Преимущества (3 колонки)**: Рефрижераторный склад, прямая доставка к борту/рейду, прямые контракты IMPA.
5. **О компании**: Презентация мощностей, опыт 15+ лет, сертификация ISO/IMPA/ISSA.
6. **Партнёры**: Элегантная полоса монохромных плейсхолдеров судоходных линий.
7. **Наши отгрузки (Галерея)**: Сетка с нативным **Vanilla JS Lightbox** (открытие на весь экран, листание стрелками / кнопками, ESC).
8. **Наши подразделения**: 4 карточки смежных направлений (бункеровка, таможня, освидетельствование, агентирование).
9. **Форма заявки**: Срочный расчет за 15 минут (поля: Имя, Телефон, Email, Порт/Судно, чекбокс ПДн, JS-валидация и статус отправки).
10. **Контакты**: Карточки связи, кнопки WhatsApp/Telegram, заглушка для встраивания Яндекс.Карт / Google Maps.
11. **Footer**: Повтор навигации, реквизиты, лицензии, копирайт.

## 🛠 Руководство по интеграции в тему WordPress

### 1. Разделение на шаблоны темы

1. **`header.php`**:
   - Вырезать блок от `<!DOCTYPE html>` до закрывающего тега `</header>`.
   - Заменить статический `<title>` и мета-теги на `wp_head()`.
   - Заменить меню `<ul>` на `wp_nav_menu( array( 'theme_location' => 'primary' ) )`.
   - Пути к ассетам заменить на `<?php echo get_template_directory_uri(); ?>/assets/...`.

2. **`footer.php`**:
   - Вырезать блок `<footer class="footer">...</footer>` и модальное окно `#lightbox`.
   - Перед `</body>` добавить `<?php wp_footer(); ?>`.

3. **`front-page.php`**:
   - Вызвать `<?php get_header(); ?>`.
   - Вставить содержимое секций Hero, Каталога, Преимуществ, О компании, Партнеров, Галереи, Подразделений, Формы и Контактов.
   - Вызвать `<?php get_footer(); ?>`.

4. **`page-about.php`**:
   - Для страницы `about.html`.

5. **`single-service.php` / `page-service.php`**:
   - Для шаблона страницы услуги из `service-single.html`.

6. **`page-contacts.php`**:
   - Для страницы контактов из `contacts.html`.

### 2. Пример `functions.php` для темы WordPress

```php
<?php
// Регистрация стилей и скриптов
function shipchandlers_enqueue_scripts() {
    // Подключение шрифтов Google
    wp_enqueue_style( 'shipchandlers-fonts', 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Manrope:wght@600;700;800&display=swap', array(), null );
    
    // Основной CSS
    wp_enqueue_style( 'shipchandlers-main-style', get_template_directory_uri() . '/assets/css/style.css', array(), '1.0.0' );
    
    // Vanilla JS
    wp_enqueue_script( 'shipchandlers-main-js', get_template_directory_uri() . '/assets/js/main.js', array(), '1.0.0', true );
}
add_action( 'wp_enqueue_scripts', 'shipchandlers_enqueue_scripts' );

// Поддержка меню и миниатюр
function shipchandlers_setup() {
    add_theme_support( 'title-tag' );
    add_theme_support( 'post-thumbnails' );
    
    register_nav_menus( array(
        'primary' => 'Главное меню (Header)',
        'services' => 'Меню услуг (Footer)',
        'company'  => 'Меню компании (Footer)',
    ) );
}
add_action( 'after_setup_theme', 'shipchandlers_setup' );
```

## 📱 Адаптивные брейкпоинты
- **375px+**: Мобильные телефоны (компактные отступы, выпадающее меню-бургер с аккордеоном).
- **768px+**: Планшеты (2–3 колонки в сетках, горизонтальные футер и карточки).
- **1024px+**: Ноутбуки и десктопы (полноэкранное навигационное меню с hover-эффектами).
- **1280px–1440px+**: Широкоформатные мониторы (5 колонок в каталоге, 4 в подразделениях).
